찾을 폰 연결

폰에서 "이 폰 등록"을 하면 6자리 코드가 떠요. 그 코드를 넣어주세요.

연결된 폰:

버튼을 누르면 폰이 소리치고, 폰에서 알림을 누르면 위치가 아래 지도에 떠요.

🗺️ 구글 지도에서 열기

이 폰을 찾을 수 있게 등록

1
홈 화면에 추가

아이폰: 공유 버튼 → "홈 화면에 추가" → 추가된 아이콘으로 다시 열기
안드로이드: 브라우저 메뉴 → "홈 화면에 추가" (크롬은 그냥 진행해도 돼요)

2
알림 허용

아래 버튼을 누르고 알림을 허용하면 코드가 나와요.

찾는 쪽 화면에 이 코드를 넣으세요

이 화면을 닫아도 돼요. 폰을 찾을 때 알림이 와요.
